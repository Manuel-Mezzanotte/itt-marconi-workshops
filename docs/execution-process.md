# Esecuzione del progetto

Il 25 settembre 2026 il partecipante ha chiesto di proseguire con Codex senza
consumare altri crediti Kiro, riferendo che il docente consente questa alternativa.
Questa indicazione è riportata dal partecipante; non è una modifica della traccia
originale conservata in `Exam/`.

Le specifiche e i task T-01, T-02 e T-03 di user-service sono stati elaborati
ed eseguiti con Kiro. Dal T-04 di user-service l'esecutore è Codex.
I metadati delle precedenti sessioni Kiro restano invariati; non si simulano
pressioni di Start task, sessioni Vibe o altre attività nell'IDE.

Il processo resta Requirements-First: requirements, design e tasks vengono
revisionati e committati separatamente prima del codice del servizio. Si avvia
un task alla volta, si implementa, si verifica il risultato, si spunta la checklist
e si crea il relativo commit. La cronologia Git conserva gli orari reali.

Per i bug restano issue, classificazione, branch dedicato, regressione rossa,
correzione e verifica verde. Le correzioni successive al cambio di strumento
sono eseguite da Codex, senza dichiararle sessioni Vibe di Kiro.
